# Cinematic Edit (method edition)

**Edit like an ad director, not a template.**
Raw footage in. A director's cut out.

By **Deniz Gemici**, advertising photographer and director (Ankara) · [denizgemici.com](https://denizgemici.com)

This folder is the edition listed in the Claude directory. It holds the complete method: frame rate first, watching every clip end to end, artistic shot judging, one idea per film, twelve structures, slow motion and speed ramps, log colour, cutting to music, checks and an independent critic. Every measurement is done with plain `ffprobe` / `ffmpeg` recipes (`skills/cinematic-edit/references/by-hand.md`), so it ships only text.

The full edition, with bundled measuring tools (whole-clip scanner, LUT check, beat tracker, plan checker, renderer, QC and Premiere/Resolve export), lives at the root of this repository: https://github.com/denizgemici/cinematic-edit

Requirements: `ffmpeg` and `ffprobe` installed by the user.
