# Privacy

Cinematic Edit (both editions) collects, stores and sends no data.

- It has no server, no account, no analytics and no network access.
- It reads only the media files the user points it at, on the user's own computer, and writes only into folders the user chooses (plus the system temporary folder for intermediates in the full edition).
- Nothing the skill reads or produces is sent to the author or to any third party by the skill. What the user's AI assistant does with the conversation is governed by that assistant's own privacy policy.

Questions: open an issue at https://github.com/denizgemici/cinematic-edit/issues
